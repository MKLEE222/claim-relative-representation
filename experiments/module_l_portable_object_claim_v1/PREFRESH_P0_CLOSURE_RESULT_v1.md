An intermediate portable version classified two Paul files as multiple primary objects because each main letter contained another div type=letter inside floatingText/body.

Exposed source audit established that these are embedded letters, not competing document-level primary objects.

The pre-fresh embedded-text amendment therefore froze a hierarchy:

    primary scholarly object
    embedded scholarly object
    annex/enclosure object

A primary candidate cannot be established inside:
- floatingText;
- a nested body distinct from the first primary body.

Dates inside those embedded text islands are diagnostic:

    EXCLUDED_EMBEDDED_OBJECT

and cannot enter the selected primary object's temporal claim set.

After this correction:
- Paul returned to 1515/1515 single primary objects;
- the +12 discovery/full delta remained;
- therefore the delta is not produced by embedded-object contamination.

# R3 Load-Bearing Inquiry Second-Pass Review Protocol v1

Date frozen: 2026-09-27
Status: READY FOR INDEPENDENT REVIEW; NO INDEPENDENT HUMAN RESULT CLAIMED

## Purpose

Provide a second-pass review package for the five frozen scholarly inquiries without exposing the controlled representation outcomes or requiring the reviewer to adopt the project's relation labels.

The purpose is historical adjudication reliability, not model agreement.

## Reviewer input

For each inquiry the reviewer receives only:
- the question;
- exact admissible source scope;
- source loci/pages;
- the source passages or page images;
- a response form.

The reviewer does not receive:
- the registered answer;
- controlled projection results;
- repair results;
- carrier classifications;
- claim-status labels.

## Questions

1. Pashai: Which earlier proposition does Stein corroborate, and which does he challenge?
2. Arbre Sec: Whose commitment is the cypress identification, and does the inspected entry establish Cordier's adoption of it?
3. Great Desert: Which evidence supports distance/marches, and which supports the local-folklore source attribution?
4. Urumtsi: What action description is changed by the 1920 erratum?
5. Tun-o-Kain: Does the 1920 entry present one settled route replacement or preserve competing positions?

## Required response fields

For every inquiry:
- answer in ordinary historical prose;
- source span(s) supporting the answer;
- actor/source responsible for each proposition;
- uncertainty/modality if present;
- confidence: HIGH / MEDIUM / LOW;
- unresolved ambiguity, if any.

The reviewer may answer UNRESOLVED. Forced agreement is prohibited.

## Comparison rule

After the review is sealed, compare the reviewer's answer with the registered proposition panel at the level of:
- target proposition identity;
- actor/proposition responsibility;
- stance direction where applicable;
- evidence-to-proposition assignment;
- modality/uncertainty;
- simple textual correction for Urumtsi.

Do not reduce all five inquiries to one kappa value because their outputs are structured and non-homogeneous.

Report:
- exact agreement on each registered component;
- substantive disagreement;
- reviewer-added distinction;
- unresolved component.

If a scalar summary is desired, use proportion of predeclared atomic components agreed, with the component list frozen before opening the review.

## Independence rule

An AI-assisted re-reading by the same research process is not counted as independent human adjudication.

A qualifying independent review requires a reviewer who did not construct the proposition panel or controlled projection outcomes and who completes the package before seeing the registered answers.

## Gate rule

Gate II may move from PARTIAL to HISTORICAL-REVIEW-CLOSED only if:
- all five inquiries receive a qualifying independent review;
- disagreements are adjudicated transparently;
- any changed historical reading propagates to the controlled mechanism tests before manuscript claim freeze.

Until then the status remains:
INDEPENDENT_SECOND_PASS_PENDING.

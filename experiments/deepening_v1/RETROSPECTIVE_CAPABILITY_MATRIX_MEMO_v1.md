# Retrospective capability matrix v1

Date: 2026-09-27
Status: synthesis of existing authoritative results; no pooled score.

## Result

The current evidence already rejects a single scalar interpretation of representation quality.

Observed separations include:
- evidence outside scope;
- evidence in scope but not discoverable from the entry state under the frozen policy;
- evidence discoverable only after source-grounded mediation;
- text/endpoints present but target relation ambiguous;
- relation preserved while responsibility/source-locator exposure weakens;
- endpoints preserved while editorial certainty state is lost;
- individual source-qualified assertions preserved while the complete set is not directly composable into one acyclic chronology;
- a representation exact for one task while selectively non-equivalent for another.

## Important correction

The former HELD -> ACCESSIBLE -> RECOVERABLE -> COMPOSABLE ladder should now be treated as a mnemonic, not a strict scientific ordering.

Discoverability depends on entry state and policy; recoverability depends on the relation target and contract; resolution-state fidelity and responsibility traceability are separate task-facing properties; composability concerns a set of relations rather than one relation in isolation.

## R3 use

For R3, a representation comparison should name the capability being tested rather than report a generic adequacy pass/fail.

This prevents three common errors:
1. calling an in-scope but hard-to-find witness unavailable;
2. calling endpoint preservation equivalent to preserving uncertainty/responsibility;
3. calling individually recoverable relations jointly usable without testing conflict/composition.

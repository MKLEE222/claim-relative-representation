# Current bounded scientific answer

The mother problem now has a bounded answer:

> What must survive representational change is not a fixed maximal inventory of fields or metadata. For a declared scholarly task and research entry state, a sufficient source-grounded carrier system must remain available—or be lawfully recoverable—from which the task-relevant epistemic relations and statuses can be determined, together with a workflow capable of reaching those carriers. Transformations can preserve content while altering relation determinacy, uncertainty/status, discoverability, or downstream executability; alternative carriers can sometimes restore the required capability.

A compact formal indexing is:

[
Researchability(R,	au,S,K,pi)
]

where:

- (R) = representation;
- (	au) = scholarly task;
- (S) = research entry state;
- (K) = admissible carrier/evidence contract;
- (pi) = access/transformation workflow.

This answer is supported by:
- controlled proposition-binding mechanisms;
- a natural-object null;
- an ecological access experiment;
- source-native selective access repair;
- independent external transformation/status-stage evidence.

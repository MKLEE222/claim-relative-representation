## 6. Frozen ERIR classification

For each parsed document:

    Phi_before = warrant projection from root/current admissible temporal carriers
    Phi_after  = warrant projection after opening the unique admissible origDate

Disposition:
- INELIGIBLE if object/origin binding contract fails;
- ADMISSIBLE_NULL_EVENT if contract passes and Phi_before == Phi_after;
- ERIR_ELIGIBLE if contract passes and Phi_before != Phi_after.

Transition class is the already frozen Module-P classifier:
- P-U1 CONFLICT_FORMATION;
- P-U2 RESOLUTION_OR_ACQUISITION;
- P-U3 NARROWING_OR_QUALIFICATION;
- P-U4 ALTERNATIVE_REVISION;
- OTHER;
- ADMISSIBLE_NULL_EVENT.

No transition class may be added after opening.

## 8. Source audit

For every ERIR-eligible episode, an automatic documentary audit may verify:
- the machine temporal carriers actually present;
- selected primary-object boundary;
- unique origDate carrier;
- carrier intervals;
- whether before/after warrant difference is traceable to those carriers.

The audit may not alter eligibility.

If a source-semantic ambiguity is discovered after opening:
- preserve the raw result;
- classify the affected scientific interpretation as BOUNDED_PARTIAL or INVALID as appropriate;
- do not repair and rerun as a fresh test.

## 9. One-shot execution rule

The first full opening of data/xml/editions/*.xml is the authoritative fresh run.

After that run:
- AAD is exposed forever for this project;
- changing seed, filename, wrapper, parser version or run ID cannot restore freshness;
- any later rerun is audit/development only.

## 10. Outcome categories

### INVALID
Use if:
- population accounting is incomplete;
- oracle/runtime contract disagreement remains unresolved;
- source snapshot is not the pinned commit;
- the run violates the frozen protocol.

### NULL
Use if:
- the population is valid,
- but there are zero ERIR-eligible episodes.

This is a corpus-applicability result, not model failure.

### BOUNDED_PARTIAL
Use if:
- one or more ERIR-eligible episodes exist,
- but source audit or capability execution leaves a bounded unresolved issue.

### PASS
Use only if:
- population accounting is complete;
- oracle/runtime contracts agree;
- at least one ERIR-eligible episode exists;
- every eligible episode passes P1-P7;
- comparator/failure behavior matches frozen expectations;
- source audit supports the carrier interpretation.

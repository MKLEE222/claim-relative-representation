## 3. Source-version binding

The five downloaded distribution SHA-256 values are sorted by frozen dataset slug and serialized
as canonical JSON.

Define:

    source_manifest_sha256 =
        SHA256(canonical_json({slug: distribution_sha256, ...}))

Module-R state/event source_version is:

    VGW_MANIFEST::<source_manifest_sha256>

Each source locator retains its exact dataset slug.

Therefore:

    source_version + dataset slug

deterministically identifies the exact distribution SHA-256 used for the baseline/current source.

The result artifact must preserve the full slug -> SHA-256 manifest.

## 4. PRE_DATA state

PRE_DATA includes only:
- checkout;
- dependency installation;
- Python compilation;
- frozen Git-blob verification;
- Module-R synthetic controls;
- VGW-shaped pre-fresh synthetic controls;
- bounded metadata-only source-anchor verification;
- compilation of the authoritative runner and documentary auditor.

No provider distribution URL may be fetched in PRE_DATA.

A failure here is:

    PRE_DATA_ABORT

and is recoverable if the scientific blobs and contracts remain unchanged.

## 5. DATA_OPEN event

The irreversible opening job starts only after PRE_DATA succeeds.

Immediately before the first provider distribution GET, the workflow writes:

    DATA_OPEN_EVENT_v1.json

containing:
- workflow run ID;
- GitHub SHA;
- UTC timestamp generated by the runtime;
- frozen source slugs;
- protocol identifier;
- scientific engine blob IDs.

The marker is uploaded with the result artifact even if the run later fails.

The first GET request to any frozen distribution content URL is the irreversible fresh boundary.

## 6. Download rule

Download exactly the five URLs frozen in:

    VGW_DISTRIBUTION_METADATA_ANCHORS_v1.json

No URL substitution or discovery occurs after DATA_OPEN.

For each response:
- require HTTP success;
- require N-Triples-compatible content;
- read the complete response;
- verify actual byte length against the frozen content_size metadata where the server transfer
  yields an exact body length;
- compute SHA-256;
- save the bytes only in the workflow-local source cache.

No retry may switch to another source/version.

Network retry of the identical frozen URL is an execution retry after data opening and does not
restore freshness.

## 7. Oracle/runtime agreement

Run both frozen extractors on the exact same downloaded byte map.

Remove only the top-level implementation label:

    engine

before equality comparison.

Any remaining disagreement is:

    ORACLE_RUNTIME_UNRESOLVED

and the confirmatory result is INVALID.

No natural-case repair is permitted.

Preserve per dataset:

Preserve cross-dataset:
- all case dispositions;
- works_after_1970 role exclusions;

- admissible null count;
- every ineligible/unresolved disposition count.

No candidate is dropped from reporting because it is inconvenient.

## 9. Module-R execution

For every:

    SUBSTANTIVE_CANDIDATE

run the frozen Module-R oracle transition and runtime transition.

Required:
- expected class = R-U3_EVIDENTIAL_STATUS_REVISION;
- R1-R8 all pass;
- strong comparator behavior matches the frozen evaluator;
- wrong-object/source-version/missing-applicability controls reject;
- no-history preserves result/provenance/transition but fails delayed history.

Natural null cases are executed and must remain:

    ADMISSIBLE_NULL_EVENT

with no substantive Psi change.

## 10. Independent documentary audit

The documentary auditor must not import:

    vgw_oracle
    vgw_runtime

It may use RDFLib directly on the downloaded raw N-Triples.

For every substantive candidate it verifies exactly:
- one baseline object with the registered F-number;
- one current provider object with the same F-number;
- baseline slug = de_la_faille_1970;
- current slug is one frozen current provider;
- exactly one current Production;
- exactly one addressable E13 AttributeAssignment connected through P141i;
- assignment type includes previous_attribution;
- exactly one P141_assigned Production;
- assigned Production identifies Van Gogh through one frozen Van Gogh identifier;
- event evidence_id equals the source assignment URI;
- provider slug and source distribution SHA-256 match the preserved source manifest;
- responsible agent matches when exactly one is encoded.

The audit does not choose eligibility or alter transition classification.

## 11. Outcome

INVALID if:
- PRE_DATA scientific blob check fails after data opening somehow proceeds;
- source download/accounting is incomplete;
- oracle/runtime disagree;
- substantive Module-R execution disagrees/fails;
- documentary audit fails any substantive candidate.

NULL_APPLICABILITY if:
- zero admissible matched baseline/current attribution cases.

NULL_REASSESSMENT if:
- admissible matched cases exist;
- all are natural nulls;
- zero substantive candidates.

PASS if:
- at least one substantive candidate exists;
- all substantive candidates pass R1-R8;
- natural nulls remain null;
- strong comparator behavior matches;
- documentary audit passes every substantive candidate.

No post-opening scientific amendment can convert an INVALID/NULL/PARTIAL result into the
authoritative fresh result.

## 12. Artifact preservation

Upload, even on failure:
- DATA_OPEN_EVENT_v1.json;
- distribution_manifest_v1.json;
- authoritative_results_v1.json;
- documentary_audit_v1.json;
- run_summary_v1.json.

Raw provider distribution bytes are not uploaded to the repository or user-facing artifact.
They remain transient workflow inputs.

## 13. Freshness ceiling

If DATA_OPEN never occurs:
- PRE_DATA failures are recoverable.

Once DATA_OPEN occurs:
- VGW distributions are exposed forever for this project;
- the first opened execution is authoritative for fresh status;
- any later corrected execution is reproduction/audit only.

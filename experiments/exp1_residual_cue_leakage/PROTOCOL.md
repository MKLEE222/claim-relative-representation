# Experiment 1A - Residual-cue leakage after one-coordinate ablation

Date frozen: 2026-09-23

## Question

When an explicit CEDL coordinate is removed while substantive text is held fixed, does the retained text still contain direct lexical cues from which that coordinate can be recovered?

This experiment does **not** evaluate retain/revise/defer/withhold. It tests whether the current one-coordinate operators create true unavailability or merely convert an explicit relation into a textually recoverable one.

## Scope

Ten frozen Yule-Cordier events: PM01-PM04, KS01-KS04, CL01-CL02.

Coordinates audited:

- attribution
- temporal_order
- evidence_relation
- claim_binding

Normalization is excluded from Experiment 1A because it is a distinction-collapse operator, not simple metadata removal.

## Measurement

For each event/coordinate pair:

1. start from the frozen source-facing event text;
2. remove the explicit structured coordinate;
3. keep the text unchanged;
4. apply a predeclared lexical-cue detector;
5. record whether a residual cue remains.

The detector is deliberately conservative. A positive result means only that an explicit textual cue survives. A negative result does not prove semantic unavailability.

## Predeclared cue families

### attribution
Named source/editor/scholar markers and direct source-reporting constructions:
`Bretschneider`, `Laufer`, `Tanner`, `Moule`, `Richthofen`, `Queen`, `Pauthier`, `G. Text`, `H. C.`, `writes to me`, `citing`.

### temporal_order
Explicit cross-layer or sequencing cues:
`Regarding ... statement`, page back-reference, `later`, `addendum`, `prior`, `after`, `in 1901`, `1915`, `1919`, or explicit earlier-edition reference.

### evidence_relation
Lexical constructions that directly mark support/challenge/qualification/update:
`error`, `correct`, `wrong`, `only one`, `merely`, `shows`, `conclusion`, `neither ... nor ... but`, `future`, `probable`.

### claim_binding
Frozen subject terms that make the claim target lexically recoverable:
paper-money/mulberry/bark; Kinsay/Hang-chau/revenue/eyewitness-style travel reference; coal/black stones/fuel.

## Falsification / interpretation

If a removed coordinate still has a residual cue, the intervention is classified as:

`explicit -> recoverable`

not `explicit -> unavailable`.

If this is common on load-bearing events, metadata-only ablation is insufficient for the main intervention study and must be replaced by a stronger but realistic projection operator.

## Negative controls

The audit also records cue hits on events whose frozen claim dependencies do not include the tested coordinate. Systematic cue hits in matched controls indicate that the cue family is too broad and must be refined before any claim-consequence experiment.

## Status

Exploratory mechanism experiment. It can invalidate the current operator family but cannot establish the final humanistic claim effect.

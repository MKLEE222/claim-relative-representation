# Claim-Relative Representation

Public research repository for studying when changes in digital representation alter the evidential relations needed to sustain specific humanistic claims.

## Current phase

**Scientific-object validation.** The repository is not yet claiming a validated general method. The first empirical carrier is the Yule-Cordier Marco Polo edition history. We are testing whether a Claim-Evidence Dependency Layer (CEDL) can be source-grounded, independently audited, selectively intervened on, and restored without changing the frozen humanistic target.

Five acceptance gates are frozen at project start:

1. Humanistic significance
2. Transformation realism
3. Claim-evidence validity
4. Selective causality with matched negative controls
5. Restoration

Failures and BLOCKED states are retained rather than repaired post hoc.

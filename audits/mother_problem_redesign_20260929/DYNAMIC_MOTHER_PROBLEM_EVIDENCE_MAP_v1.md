## 2. Mother problem at two levels

### Static / within-state researchability

Existing E1-E6 establish separations among:

    content presence
    target discovery
    carrier-set exposure
    relation determinacy
    provenance/responsibility
    resolution-state fidelity
    downstream executability

Current static index:

    Researchability(R, tau, S, K, pi; B)

### Dynamic / across-state researchability

The later J-P-Q-R line asks a different question:

> When scholarly evidence, judgments or editorial states change, what must remain bound and
> recoverable so that the transition itself remains warranted, selective and historically
> auditable?

The dynamic capability set now includes at least:

    O1 ObjectIdentity
    O2 ClaimApplicability
    O3 TargetDeterminacy
    O4 ResultDeterminacy
    O5 Selectivity
    O6 ProvenancePreservation
    O7 TransitionCompatibility
    O8 HistoryRetention

A useful bounded dynamic abstraction is:

    DynamicResearchability(S_t, E_t, A_t, T; K, O)

where:
- S_t = scholarly state;
- E_t = evidence / reassessment event;
- A_t = admissible action/update semantics;
- T = retained transition history;
- K = source/carrier contract;
- O = scholarly-object identity/boundary contract.

This is an integrative framework, not a universal theorem.

is no longer only an organizing hypothesis.

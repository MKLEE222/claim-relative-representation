## 1. Goal

The audit decomposes false scholarly-action availability across three progressively stronger
representations:

    B_RELATION_TARGET
    B_LIVE_TARGET
    Q_FULL_HISTORY

The negative labels are inherited from pre-data frozen conditions:
- natural T8 non-live target cases;
- registered same-current-state history ablations.

They are not generated by comparator outcomes.

## 4. Natural live-target false positives

    B_RELATION_TARGET false availability = 47/47
    B_LIVE_TARGET false availability     = 0/47
    Q_FULL_HISTORY false availability    = 0/47

The incremental distinction:

eliminates all 47 natural false action availabilities without losing a positive response context.

This establishes:

    functional relation edge
    !=
    lawful current target

in the frozen ecology.

## 5. Same-current-state history false positives

eliminates all 52 controlled false action availabilities without losing a positive response
context.

This establishes:

    current live target
    !=
    history-qualified future action

under the registered response task.

"more metadata is better" effect.

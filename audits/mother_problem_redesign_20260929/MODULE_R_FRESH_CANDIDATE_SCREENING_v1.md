### 3.1 Humanities / DH fit

Van Gogh Worldwide is a cultural-heritage research infrastructure integrating scientific
art-historical and technical information across institutions.

Its public documentation explicitly states that:
- changing and uncertain artist attributions are represented with Linked Art
  AttributeAssignment activities;
- a former attribution to Vincent van Gogh is classified with the project concept
  previous_attribution;
- the assignment can preserve the actor responsible for the assignment and a timespan during
  which that attribution was held;
- the platform distinguishes works no longer recognized as authentic from works whose status
  remains questionable;
- the project aims to include scholarly opinions rather than collapse them into one undocumented
  final value.

This is a direct non-temporal neighbor of Module R.

### 3.2 Candidate scholarly transition

The primary candidate target is:

    creator / authenticity attribution of one artwork object

A bounded event pattern is:

    earlier scholarly attribution
    -> curator/researcher AttributeAssignment / reassessment
    -> current or historical attribution status

Unlike Module Q, the task-relevant value is not a document date.

### 3.3 Natural historical anchor

Van Gogh Worldwide starts from the oeuvre defined in:

    J.-B. de la Faille, The Works of Vincent van Gogh: His Paintings and Drawings (1970)

The public catalog contains a dedicated linked-data dataset:

    de_la_faille_1970

and a separate:

    works_after_1970

dataset for artworks attributed to Van Gogh after the 1970 catalogue.

This gives a prospectively meaningful baseline/later-knowledge ecology without selecting records
according to their observed attribution outcome.

### 3.5 Current strengths

Project-native model supplies:
- object identity;
- production/creator target;
- AttributeAssignment identity;
- assigned value;
- assignment actor where supplied;
- attribution validity timespan where supplied;
- explicit previous-attribution classification;
- institutional provider provenance.

This is much closer to Module-R target/provenance/history semantics than another temporal
origDate-style corpus.

### 3.6 Current unresolved question

The public modelling example does not guarantee that every natural previous-attribution
assignment binds an explicit scholarly literature/evidence object to the assignment.

Therefore the fresh study must distinguish:

    assignment provenance
    !=
    evidential justification

If natural records preserve assignment actor/time/status but not an evidence source, that is a
scientifically meaningful bounded-partial outcome, not a reason to repair the representation.

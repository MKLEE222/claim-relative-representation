# Empirical finding map after Module O / before Module P

Date: 2026-09-29
Status: research-state consolidation; not manuscript prose.

## F-A Static researchability is layered, not scalar

Existing E1-E6 support distinctions among:
- content presence;
- target-entry discovery;
- carrier-set exposure/completeness;
- relation determinacy;
- provenance/responsibility traceability;
- downstream executability.

The empirical object is therefore not one global representation-quality score.

## F-B Dynamic researchability contains separable scholarly obligations

Modules J-L-N identify distinct obligations including:
- object identity;
- claim applicability;
- result-state fidelity;
- selective update;
- current provenance;
- transition compatibility;
- retained transition history.

Module N shows preregistered capability crossovers rather than one large ablation failure.

Development-stage implication:

    scholarly obligations are empirically separable under the frozen mechanism.

This does not yet establish universal necessity.

## F-C Current-state recovery is not scholarly-history recovery

Module M establishes strong positive comparators on exposed Berlin/Paul trajectories.

B_CURRENT_REOPEN:
- exact current state/provenance recovery.

B_ORDERED_SNAPSHOTS:
- exact current state/provenance;
- exact adjacent-state differences.

Yet distinct event histories can be observationally identical under those regimes.

Development-stage implication:

    state recovery / version diff
    !=
    transition-semantic / delayed-history determinacy

for the registered historical audit task.

## F-E The original dynamic task is specifically ambiguity-triggered inquiry

The frozen Module-I question requires:
- at least two visible t0 root temporal carriers;
- D1 disjointness or D2 uncertain non-identical overlap;
- only then lawful OPEN_ORIGIN.

This tests:

    visible ambiguity
    -> question emergence
    -> evidence acquisition
    -> warrant revision

It remains scientifically valid but is narrower than the mother problem.

## F-F AMP exposed a second dynamic regime

Post-hoc AMP diagnostics show among 48 valid objects:
- 37 have exactly one visible sent claim;
- 11 have no machine-readable t0 temporal claim;
- all 48 have a single admissible later origDate;
- 21/48 have a substantive Phi(W_root) != Phi(W_post).

Observed exposed development patterns include:
- exact sent state -> disjoint origin alternative formation;
- unresolved state -> later source-grounded warranted state.

This supports defining, but does not confirm, a second task:

    evidence-release-induced scholarly revision.

## F-G The mother-problem dynamic space now has at least two axes

Regime A:
    ambiguity-driven question emergence.

Regime B:
    evidence-driven knowledge revision.

These regimes share object/applicability/provenance/selectivity/history obligations but differ in
how the research question/update is activated.

A strong paper-level contribution should not conflate either regime with all of scholarly
researchability over time.

## Remaining empirical gaps

G1. Validate Regime B as a mechanism on synthetic + exposed development evidence.
G2. Obtain fresh independent confirmation for an eligible Regime-B population/event ecology.
G3. Move beyond temporal dating to a second non-temporal humanities event family
    (e.g. attribution/evidential-status revision).
G4. If historical Yule-Cordier readings remain load-bearing, obtain independent human scholarly
    adjudication.
G5. Whole-object prevalence remains optional unless a frequency claim is introduced.

## Experiment discipline from this point

A new experiment enters the core program only if it:
- distinguishes two live scientific explanations;
- closes G1-G4;
- or tests a preregistered non-substitutability claim.

Do not add engineering merely because another TEI edge case can be imagined.

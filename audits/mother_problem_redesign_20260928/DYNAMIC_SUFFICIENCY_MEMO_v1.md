# Dynamic sufficiency revision memo — after Modules D1 and D2

Date: 2026-09-28
Status: THEORY-DESIGN UPDATE FROM EXECUTED DEVELOPMENT RESULTS. NOT A NEW THEOREM.

## 1. What D1/D2 changed

The previous continuation framing risked treating representational sufficiency as a property of retained state alone.

Two pre-diff-frozen natural Whitman revision events reject that simplification.

D1:
- 1 natural certainty change;
- 1,435 unaffected relations;
- endpoints unchanged;
- coarse locus status plus identity-rich patch is sufficient at the affected locus.

D2:
- 141 natural certainty changes;
- 7 relation additions;
- 8 relation removals;
- 1,287 unaffected relations;
- 113 affected loci;
- coarse endpoint/count state plus identity-rich patch is sufficient on all 113 affected loci.

Thus failure to retain a binding in the pre-event state does not imply dynamic failure when the revision channel later supplies that binding lawfully.

## 2. Revised object of sufficiency

For dynamic inquiry, evaluate a tuple:

    (S_t, E_{t->t+1}, A, T)

where:
- S_t = retained research state before revision;
- E_{t->t+1} = information delivered by the revision/evidence event;
- A = lawful source/access operations;
- T = continuation task family.

A bounded dynamic sufficiency condition is:

    if two admissible histories induce the same available tuple
    (S_t, E, A-observations)
    then they must induce the same warranted continuation output for T.

This is an ordinary determinacy criterion applied to the whole available information interface, not a claim of a novel theorem.

## 3. Consequence for carrier claims

Do not state:

    every relation needed in a future revision must be retained in S_t.

Instead state a distributed obligation:

> Every distinction required by the continuation task must be available at decision time from the retained state, the admissible incoming evidence/event channel, lawful source reopening, or a declared composition of these resources.

The scientific question then becomes which information can be safely delegated to later event channels or source access, at what cost and under what assumptions.

## 4. New separation target

A stronger experiment now needs two available-information interfaces that agree on:
- current scholarly answer;
- retained state;
- source/access contract as appropriate;

but differ in revision-channel information such that one cannot determine the correct selective update.

Natural revision targets from D1/D2 should be retained.
Only the channel representation is controlled.

Candidate channels:
- FULL_DELTA: relation identity + old/new status + add/remove identity;
- TARGET_NEW_ONLY: relation identity + new status, no old state;
- LOCUS_AGGREGATE_NOTICE: printed locus + aggregate count/status change, no endpoint binding;
- REVISION_NOTICE_ONLY: commit-level notice that certainty/relations changed;
- SOURCE_REOPEN: exact child source available;
- NO_EVENT: no revision information.

The channel ablation must not be advertised as a naturally broken archive.

## 5. New causal question

The next test is not:

    does full binding help?

It is:

> How can the information obligation for warranted selective revision be distributed across stored state, incoming revision evidence, and source reopening?

This is closer to the mother problem because a sustained research system operates through repeated state/event/access interactions rather than isolated static records.

## 6. Claim discipline

D1/D2 support:
- natural selective editorial epistemic revision exists;
- exact targeted updates can preserve unaffected relation claims;
- event-channel information can substitute for missing pre-state binding in bounded cases.

D1/D2 do not support:
- state binding is unnecessary generally;
- commit diffs are the only lawful event channel;
- the child editorial state is historically truer;
- global minimality;
- independent cross-domain transfer.

## 7. Relation to Modules A-C

A/B:
current answer can omit distinctions needed for later source-grounded branching.

B2:
global uncertainty amount can omit endpoint-specific evidence-selection binding.

C:
fixed symbolic relations can have time-varying source-route executability.

D1/D2:
future revision obligations can be supplied jointly by retained state and later identity-rich evidence.

Together these results point toward an interaction-level representation problem rather than a static field checklist.

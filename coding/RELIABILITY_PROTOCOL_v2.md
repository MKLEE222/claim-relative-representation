# Two-Stage Reliability Protocol v2

Date frozen: 2026-09-25

## Stage A documentary coding

Primary statistics:
- exact set agreement on D_* relations;
- mean Jaccard on D_* relation sets;
- exact representation-status agreement;
- event-level disagreement ledger.

Stage A coders never see Stage-B labels or provisional warrant states.

## Stage B epistemic adjudication

Stage B is run only after the documentary packet/reference is frozen.

Each independent adjudicator records:
- E_* relation set;
- warrant state;
- one-sentence evidence rationale;
- unresolved dependency if DEFER.

Report:
- exact E_* set agreement;
- Jaccard E_* agreement;
- exact warrant-state agreement;
- disagreement matrix by condition;
- adjudication record.

No aggregate threshold can rescue disagreement on the paper's load-bearing transition.

## Independence

The author may produce a development ledger, but it is not counted as independent reliability.

LLM/self-recoding is not an independent coder.

A confirmatory warrant-consequence result requires at least one non-author independent adjudication; stronger reporting uses two independent adjudicators plus source-based reconciliation.

## Outcome firewall

Before independent Stage-B responses are returned:
- condition identifiers are masked;
- author provisional states are absent;
- expected effect direction is absent;
- retrieval-policy names are absent.

# Documentary Coding Manual v2

Date frozen: 2026-09-25
Status: STAGE A ONLY

## Scope

Code only source-verifiable documentary relations.

Do not answer whether evidence supports, challenges, rehabilitates, qualifies, or warrants a humanistic claim.

## Allowed labels

- D_ATTRIBUTION
- D_ATTACHMENT
- D_TEMPORAL_SUCCESSION
- D_CITATION_DERIVATION
- D_REFERENT_BINDING
- D_WITNESS_DIFFERENCE
- D_EDITORIAL_LAYER
- D_MODALITY_MARKER
- D_DIGITAL_ASSEMBLY
- D_EXPLICIT_POINTER

## Forbidden Stage-A labels

SUPPORTS
CHALLENGES
UNDERCUTS
QUALIFIES_AUTHORITY
REHABILITATES
ACCRETES_INTERPRETATION
retain
revise
defer
withhold

If a coder feels one of these is needed, record the documentary facts and leave the epistemic question to Stage B.

## Representation status

For each required documentary distinction:

- EXPLICIT
- RECOVERABLE
- UNRESOLVED
- UNAVAILABLE

Higher reconstruction burden alone is not UNAVAILABLE.

## Binding rule

D_REFERENT_BINDING is allowed only when the source/native representation itself supplies an identity/pointer basis.

An analyst's conclusion that a passage "bears on claim C" is not D_REFERENT_BINDING.

## Uncertainty

When materially different documentary assignments remain compatible:
- choose UNRESOLVED;
- list alternatives;
- do not force a point label for agreement statistics.

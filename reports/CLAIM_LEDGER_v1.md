## C1 - Task-relative representation adequacy

Claim:
> A scholarly representation is not globally adequate or inadequate; adequacy depends on the frozen scholarly task and recovery contract.

Status: SUPPORTED AT CURRENT SCOPE

Primary evidence:
- Frankenstein C17 holdout: alignment task succeeds while manuscript surface/zone geography is not explicitly carried through;
- Whitman: endpoint-link task survives certainty removal while certainty-status task does not;
- Faust: temporal conflict structure and source-audit tasks require different carrier coordinates;
- Scrivener: full page+line pointer and page+reading are task-equivalent for the frozen localization task, while reading-only is not.

Not claimed:
- universal representation ranking;
- universal superiority of richer metadata.

## C3 - Minimal sufficient carrier families

Claim:
> Under a fixed scholarly task, there can be minimal carrier sets that preserve task output, and the required set changes across tasks.

Status: SUPPORTED

Primary evidence:
- Scrivener localization: page + old reading sufficient; line redundant; reading alone ambiguous;
- Frankenstein C18: witness identity + native reading-group membership sufficient; witness identity + reading-string equality not sufficient;
- Whitman endpoint recovery: print locus + manuscript file + manuscript local locus;
- Faust conflict structure: ordered items; source-audit task additionally requires source identity.

Not claimed:
- globally minimal file representation;
- minimal storage size;
- unique minimal family in all cases.

# Design audit v5 - task realism and mechanistic interactions

Date: 2026-09-24

## Disposition

**DO NOT RUN CLAIM-STATE EXPERIMENT YET.**

The design now separates task realism, candidate distinction hypotheses, carrier-aware recoverability, typed transformations, and preregistered interaction mechanisms.

## Task realism

The current task family is treated as a set of instrumented scholarly microtasks, not as a universal decomposition of humanities research.

A new realism audit maps the tasks to established activity-centered accounts of humanities work while keeping a strict boundary between:

1. a natural-language scholarly task surface; and
2. the project's analytical coding layer.

This is especially important for tau_relation: participants should answer how passages bear on one another in ordinary scholarly language; the CEDL primitive relation labels are assigned in a separate blinded coding step.

## Main effects versus interactions

Main effects remain necessary because they diagnose carrier substitution and burden changes.

However, Experiment 1A showed why main-effect nulls cannot be interpreted as global irrelevance. A structured carrier may be removed while a lexical or contextual carrier preserves the task.

The first interaction wave is therefore limited to **carrier-substitution / carrier-exhaustion interactions**.

No all-pairs search is permitted.

## Frozen first-wave interaction logic

A confirmatory interaction requires:

1. a frozen task;
2. a target candidate distinction;
3. a frozen baseline carrier family;
4. T1 that removes/hides one carrier;
5. a preregistered substitution route;
6. T2 that restricts the substitute carrier;
7. a 2x2 baseline/T1/T2/T1+T2 block;
8. claim-state outcomes still sealed.

Eight first-wave blocks are frozen across paper money, Kinsay eyewitness, and coal-note tasks.

## Strongest possible witness

The highest-value mechanistic pattern is:

- T1 alone preserves task output;
- T2 alone preserves task output;
- T1+T2 makes the relation unresolved/unavailable or the task non-executable;
- carrier coding confirms that T1 forced substitution onto the carrier removed by T2;
- restoring either carrier reverses the joint failure.

This would establish a claim-relative representational interaction without relying on a generic statistical interaction coefficient.

## Important holdouts

- TD_NORMALIZE remains outside the first wave pending semantic-preservation audit.
- TA_EXTERNAL remains sensitivity-only.
- attribution interactions are not automatically included; they require a carrier map showing that attribution is not already intrinsic to the focal span.
- I2 dependency-conjunction interactions are postponed until primitive recoverability coding is stable.

## Next admissible step

Before executing the eight interaction blocks, the project should construct the actual R00/R10/R01/R11 representation objects and run static invariance/cue audits on them.

The next experiment is therefore a **representation construction audit**, not a humanistic outcome experiment.

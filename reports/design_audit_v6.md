# Design audit v6 - anti-idealization and ecological anchoring

Date: 2026-09-24

## Problem addressed

A reviewer could reasonably object that a source-aligned CEDL reference plus controlled ablations is a researcher-built ideal world: the experiment may prove only that the representation designed to contain the answer outperforms versions from which answer-relevant coordinates were removed.

The design is revised to make that objection testable rather than rhetorical.

## Key separation

The repository now distinguishes:

- N: independently existing native representations;
- W: documented workflow replays;
- C: controlled projections for identification;
- R: source-aligned reference reconstruction.

R is explicitly barred from serving as the ecological baseline or as an "ideal edition."

## Claim ceilings

Controlled projections can support mechanism claims but not prevalence/ecological claims.

A statement such as:

> removing structured chronology shifts recovery to lexical cues

is admissible from C.

A statement such as:

> real digital editions systematically make chronology hard to recover

requires N/W convergence.

## Access tasks

The paper-money dry run exposed a second artificiality risk: giving PM01-PM03 to the evaluator pre-solves discovery.

The revised design therefore distinguishes:

- access tasks with realistic seed states and real object navigation/search;
- relation tasks where endpoints are deliberately supplied and discovery is held fixed.

The paper must never interpret a fixed-endpoint relation task as evidence about discoverability.

## Gate T revision

T now contains:

- T1 operation realism;
- T2 representation provenance;
- T3 ecological anchoring.

Current status:
- T1: design pass for the core operator family;
- T2: pass after N/W/C/R classification;
- T3: partial, because workflow replays and natural contrast analyses remain to be executed.

## Next step

Before human outcome collection, build at least one W object for each first-wave transformation family and compare its carrier state with the corresponding C projection.

The controlled experiment should be treated as a mechanism microscope; the native/workflow objects establish that the mechanism is not merely an artifact of the microscope.

# Design Audit v7 — Post-External-Validation and Pre-Final-LLM

Date: 2026-09-26

## Revision from v6

v6 correctly identified the danger of treating an author-built reference reconstruction as an ecological ideal and marked ecological anchoring as partial.

Since then, the project has added independent/native evidence from Frankenstein Variorum, the Walt Whitman Archive, Digital Faust, and Scrivener, plus task-relative minimal-carrier tests.

## T1 — operation realism

PASS for the current task families.

Access, documentary localization, endpoint recovery, editorial grouping, temporal conflict detection, and source audit are expressed using native or workflow-grounded operations rather than only synthetic coordinate deletion.

## T2 — representation provenance

PASS.

Native (N), workflow (W), controlled (C), and source-aligned reference (R) roles remain distinct.
R is not used as the ecological baseline.

## T3 — ecological anchoring

PASS AT SCOPED MECHANISM LEVEL.

Independent/native systems instantiate the framework without being re-encoded into one common benchmark:
- Frankenstein: alignment-enabling task adaptation with selective loss/non-carry-through of source geography;
- Whitman: endpoint linkage separable from encoded certainty;
- Faust: raw temporal assertion presence separable from conflict-resolved executable chronology;
- Scrivener: documentary pointer detail contains task-redundant and task-necessary coordinates.

This does NOT establish ecological generality for the paper-money warrant consequence itself.

## Primary-case warrant status

J0 demonstrated operational closure but is development-only because it used the same-session model and an earlier packet design.

The confirmatory computational warrant design now requires:
- atomic material-identification claim;
- exact source spans;
- deduplicated unique evidence units;
- equal unique-unit budget;
- PM03 add-back rescue;
- non-PM03 sham add-back;
- PM03 removal with controlled donor replacement;
- fresh/stateless or model-separated final LLM replication.

## Current ceiling

The representation framework has crossed the earlier T3 bottleneck for mechanism claims.

The remaining bottleneck is no longer ecological anchoring in general; it is selective causal closure of the primary-case operational warrant consequence.

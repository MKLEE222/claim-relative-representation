# LLM Judge Disposition v1

Date: 2026-09-26

## Decision

The LLM-judge route is closed as the primary warrant-measurement layer for the current paper.

The frozen three-model experiment produced:
- one perturbation-sensitive judge;
- two stable but completely insensitive judges.

Therefore the project will not tune prompts or search for a model that returns the desired selective-restoration pattern.

## Scientific interpretation

The failure is informative:

Textual access to a source assertion and objection is not sufficient to guarantee that a generic LLM will preserve the intended defeasible evidential relation.

This is directly consistent with the broader representation problem:

`lexical presence != relation-sensitive warranted use`.

## Next measurement layer

The downstream consequence will be reformulated as a transparent, contract-relative formal argumentation status derived only from page-verified archival stance relations.

The formal semantics is not claimed as human judgment or historical truth.

LLM results remain as an instrument stress test / negative validation layer.

# Paper-Money Target-Identity Metric Audit v2

Date: 2026-09-25
Status: STATIC PROOF; SUPERSEDES THE PRECAUTIONARY BLOCK

## Question

Could the original rule |start(candidate)-start(target)| < STRIDE count a neighboring sliding window as the target even when the candidate itself did not contain the target anchors?

## Construction fact

In E1, E1D, and E1W:

- candidate windows are generated by range(0, ..., STRIDE);
- the target window is selected from the same sliding-window grid used by the relevant candidate population;
- STRIDE = 90.

Therefore every candidate start and target start is an integer multiple of 90.

For integers a,b on that grid, |a-b| < 90 implies a=b.

So the original proximity expression is not actually a neighboring-window tolerance under these constructors. It is an equality test on window start, written indirectly.

## Per-experiment check

### E1
Target is selected from w2 = windows("V2", ...). Declared-collection candidates contain V2 windows from the same grid, and the code also requires the same document. A counted target candidate is therefore the exact target window.

### E1D
Target is selected from ws["V2"]. Named-source/domain candidates are subsets of ws["V1"] + ws["V2"]. The helper requires the same document and start-distance < stride. On the shared V2 grid this implies identical start.

### E1W
Target and source/domain candidates are all selected from the same make_windows(addenda) list. Start-distance < stride therefore implies identical start.

## Why the printed snippet looked suspicious

The log displayed only the first 20 tokens of a 180-token candidate window. The PM03 anchor can occur later in that same window. A snippet that does not visibly show the target anchors is therefore not evidence that the candidate lacks the target.

## Disposition

The previously recorded E1/E1D/E1W target ranks/ordinals remain valid under the existing window identity contract.

The stricter candidate-contained-anchor audit remains useful as a readability check, but it is not required to repair the scientific metric.

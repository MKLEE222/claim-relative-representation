# External Validation Execution Plan v1

Date: 2026-09-24
Status: PLANNED, NO OUTCOMES OPENED

## Execution order

### Stage X1 - Frankenstein Variorum

Reason for first position:
- data are explicitly published for reuse;
- the project documents its representation transformations in unusual detail;
- its workflow already contains a natural task-adaptive flattening step;
- it can test whether the framework handles **beneficial** representation transformation rather than assuming that richer structure is always better.

First action:
- freeze one published collation chunk;
- identify the corresponding source representations and spine/app apparatus;
- define ALIGN / VARIANT / STRUCTURE tasks using the project's native semantics;
- run only a static mapping audit before any controlled projection.

### Stage X2 - Walt Whitman Archive

Reason for second position:
- strongest external material for epistemic restraint;
- editorial policy explicitly distinguishes printed apparatus from looser manuscript relations;
- useful for testing whether the framework preserves weaker editorial commitment rather than coercing all relations into certainty.

First action:
- locate one public variorum relation file and its linked manuscript/notebook TEI;
- freeze a printed segment and the native linked relations;
- define LINK / RELATION-STATUS / UNCERTAINTY tasks;
- do not invent confidence values absent from the source.

### Stage X3 - Digital Faust Edition

Reason for third position:
- strongest external graph/provenance case;
- Macrogenesis exposes source, ignore/delete, weight and conflict information;
- graph complexity is higher, so it should enter after the basic external mapping discipline is validated.

First action:
- freeze a small witness-centered subgraph with retained and conflicting assertions;
- preserve source URIs and native conflict flags;
- define SOURCE / TEMPORAL / CONFLICT / ORDER-ENTITLEMENT tasks;
- avoid treating one computed order as ground truth.

### Stage X4 - Scrivener external transition holdout

Reason:
- useful cross-object historical episode;
- but still researcher-selected/constructed, so it cannot replace P1-P3 independent DH validation.

### Stage X5 - ELTeC methodological use

ELTeC informs sampling/reporting discipline only in the current paper.
No experimental result is planned unless a new task is separately preregistered.

## No pooled leaderboard

The paper will not report an aggregate "accuracy across datasets."

Instead, each external material answers a different falsification question:

- Frankenstein: can task adaptation be beneficial and still fit the framework?
- Whitman: can the framework preserve limited/possible relation entitlement?
- Faust: can it preserve provenance/conflict-sensitive temporal entitlement?
- Scrivener: can a newly constructed historical episode transfer the workflow?
- Yule-Cordier: can these representation effects reach humanistic warrant?

## Promotion criterion

The external portfolio supports a broader framework claim only if:
- at least two independent DH materials map without changing their native task semantics;
- at least one produces a boundary/null/adverse result that is retained;
- no source is re-encoded solely to make the framework succeed.

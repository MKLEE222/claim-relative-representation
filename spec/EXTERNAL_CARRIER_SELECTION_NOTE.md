# External Carrier Selection Note v1

Date: 2026-09-24

## Primary candidate

The current primary external-holdout candidate is F. H. A. Scrivener's *A Plain Introduction to the Criticism of the New Testament*, fourth edition (1894), edited by Edward Miller.

Selection is based on structure, not retrieval success:

- it is a public-domain scholarly reference work;
- Project Gutenberg exposes both volumes as native digital objects;
- the fourth edition is explicitly edited by a later editor;
- the digital object contains an explicit "Addenda Et Corrigenda" layer;
- corrections point back to earlier page/line locations;
- the editorial tradition is independent of Yule-Cordier.

No retrieval pilot has been run on this candidate.

## Why it is useful

It gives a cross-object, cross-domain editorial ecology while preserving the scientific structure needed by the framework:

earlier scholarly statement -> later editorial correction/addition -> native digital representation -> access/relation task.

This is stronger than adding another Yule-Cordier episode because it tests transport of the representation/task mechanism rather than only transport of topic vocabulary.

## Selection discipline

Before EXT_CAND_01 can become EP_EXT_01:

1. choose one transition episode using source-facing eligibility criteria only;
2. freeze the earlier seed and later target from page-verified/native witnesses;
3. define the task without target-only vocabulary;
4. freeze native object hashes;
5. bind the already-frozen Generic Access Workflow v1;
6. only then run retrieval.

If the candidate fails source verification or task realism, move to a backup candidate without inspecting retrieval outcomes.

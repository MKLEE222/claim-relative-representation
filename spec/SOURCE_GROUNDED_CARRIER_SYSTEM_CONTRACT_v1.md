# Source-grounded carrier-system contract v1

Date: 2026-09-27
Status: methodological contract derived from R3 deepening results.

## Object

For a scholarly relation or task output q, representation R, task tau, recovery contract K, and entry state E0, define a registered carrier universe C.

A carrier may be:
- explicit pointer/attachment;
- lexical/source wording;
- actor attribution;
- referent-identity bridge;
- documentary sequence/layer;
- local context;
- source locator/provenance;
- another source-grounded basis admitted by the task contract.

## Sufficient carrier set

A set S subseteq C is sufficient only when the frozen recovery procedure using exactly the declared visible inputs reproduces the registered task output.

Sufficiency is executable, not asserted from schema membership.

## Minimal sufficient family

Retain all inclusion-minimal sufficient sets rather than one selected field.

Interpretation:
- alternative minimal sets encode substitution;
- multi-carrier minimal sets encode complementarity;
- several different multi-carrier sets encode alternative composed research routes.

## Entry-state indexing

The family is indexed by E0.

A carrier set sufficient when relevant endpoints are supplied may be insufficient when the scholar must first discover the later evidence.

## Profile separation

Two sufficient sets can yield the same output while differing in:
- documentary boundary;
- candidate exposure/rank;
- assumption burden;
- responsibility traceability;
- uncertainty-state fidelity;
- number/type of traversals.

Do not reduce these to a single cost score.

## Negative evidence

A failed registered route is not automatically representation insufficiency.

Strong insufficiency requires at least one of:
- same-visible-input / different-required-output collision;
- controlled twin preserving the visible projection while changing the required answer;
- demonstrated exhaustion of every registered lawful carrier family under the contract.

## Repair

When a required relation is not recoverable, a proposed repair must:
- be source-bound;
- have explicit information footprint;
- restore the registered output;
- fail under an equally shaped incorrect binding;
- preserve an unaffected task where such a control is available.

## Claim ceiling

This contract is an audit representation for scholarly research routes. It does not claim a new general theory of database determinacy, information preservation, or human cognition.

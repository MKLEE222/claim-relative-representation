# Typed Transformation Taxonomy v2 - strict documentary/epistemic split

Date frozen: 2026-09-25
Status: SUPERSEDES v1 FOR ALL NEW SCIENTIFIC EXPERIMENTS

## Core prohibition

Representation transformations may act on documentary/digital carriers (Stage A).

They may not directly add, remove, rewrite, or ablate Stage-B epistemic labels such as:

SUPPORT | CHALLENGE | UNDERCUT | QUALIFICATION | REHABILITATION | ACCRETION | retain | revise | defer | withhold.

Those labels are adjudication outputs, not source-native representation coordinates.

## Stage A transformation layers

### TD - documentary metadata/state

- TD_ATTRIBUTION
  remove/expose explicit responsibility metadata while preserving source text.

- TD_TEMPORAL
  remove/expose explicit edition/version order metadata while preserving source text.

- TD_LAYER
  remove/expose explicit editorial-layer identity while preserving source text.

### TR-D - documentary relational interface

These transformations are permitted only on source-verified documentary relations.

- TRD_ATTACHMENT
  remove/expose an explicit note/addendum-to-target linkage.

- TRD_CITATION
  remove/expose a source/citation derivation pointer.

- TRD_REFERENT
  remove/expose a source-witnessed referent pointer/identity relation.

- TRD_POINTER
  remove/expose page/line/note/hyperlink pointers.

A constructed interface is classified as CONTROLLED unless the same relation is natively encoded by the external object.

### TA - access/context

- TA_SPAN
- TA_LOCAL
- TA_OBJECT
- TA_EXTERNAL

TA changes operational evidence scope; it does not assert deletion from history.

## Stage B

Stage B receives:
- source passages;
- verified/recovered Stage-A documentary state;
- a frozen claim;
- an adjudication policy.

It emits epistemic relation/status.

No Stage-B output is a legal transformation coordinate.

## Legacy status

The following v1/v2 names are legacy mixed-ontology constructs and are prohibited in new experiments:

- TR_EVIDENCE
- evidence_relation as a representation coordinate
- claim_binding when it means analyst-authored claim-to-evidence support
- SUPPORTS / CHALLENGES / QUALIFIES_AUTHORITY / ACCRETES_INTERPRETATION inside representation fixtures.

Old files are retained for provenance only.

## Claim binding split

- source/native pointer or explicit identity relation -> D_REFERENT_BINDING / TRD_REFERENT;
- analyst judgment that evidence bears on a humanistic claim -> Stage B only.

## Invariance requirement

Every Stage-A transformation must declare:
1. changed documentary coordinate;
2. source/native basis;
3. focal-text invariant where applicable;
4. non-target documentary invariants;
5. whether the transformation is Native, Workflow, or Controlled.

No epistemic output may be used as an invariant because it has not yet been adjudicated.

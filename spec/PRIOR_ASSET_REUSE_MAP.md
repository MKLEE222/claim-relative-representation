# Prior Asset Reuse Map v1

Date frozen: 2026-09-24
Status: INTERNAL NOVELTY / METHOD-ANCESTRY CONTROL

## Purpose

The project may reuse methodological discipline from the authors' earlier technical work, but it must not present inherited machinery as a new DH contribution.

Every borrowed component is therefore classified before manuscript drafting.

## Category A - reused methodological discipline, not new contribution

### A1 Support-feasibility gate

Inherited discipline:
do not measure downstream complexity/performance until the registered experimental object can be instantiated under the frozen contract.

Current use:
a mediation primitive is tested for source support before retrieval effect is measured.

Novelty status:
REUSED DESIGN DISCIPLINE.

### A2 Contract-relative adequacy

Inherited discipline:
representation sufficiency/equivalence is meaningful only relative to a declared objective/consequence family.

Current use:
representation adequacy is indexed by scholarly task and recovery contract.

Novelty status:
REUSED GENERAL PRINCIPLE.

### A3 Fixed target / no rescue by target change

Inherited discipline:
holding the scientific target fixed distinguishes under-measurement from a legitimately smaller scientific contract.

Current use:
failed access/mediation cannot be rescued by weakening the scholarly task after the outcome.

Novelty status:
REUSED EXPERIMENTAL DISCIPLINE.

### A4 Source binding

Inherited discipline:
positive state updates require a source-facing basis tied to the correct claim/referent/version/context.

Current use:
every mediation bridge token/pointer must be source-witnessed and bound to the frozen scholarly referent.

Novelty status:
REUSED SOURCE-AUDIT DISCIPLINE.

### A5 Partial-state reporting

Inherited discipline:
changed, certified-unchanged, and unresolved coordinates should not be collapsed.

Current use:
explicit / recoverable / unresolved / unavailable plus carrier basis and burden.

Novelty status:
REUSED REPORTING DISCIPLINE.

### A6 Separate evidence authorities

Inherited discipline:
formal, controlled, native-source, and transfer evidence have different authorities and are not pooled.

Current use:
Yule-Cordier controlled/source results and Frankenstein/Whitman/Faust external validations remain separate evidence layers.

Novelty status:
REUSED EVIDENCE-DESIGN DISCIPLINE.

## Category B - prior technical machinery deliberately NOT imported

The DH paper does not require or claim novelty from:

- Warrant Frontier Compilation;
- qualification-continuation Bellman recursion;
- canonical separating objective classes;
- neural response jets;
- probe breadth / response depth theory;
- observability rank machinery;
- persistent-write optimization.

These remain prior-paper objects.

They may be cited as methodological ancestry only where needed.

## Category C - current paper's distinct scientific objects

Candidate contributions specific to this project are:

1. **Task-adapted scholarly representation state**
   separating representation transformation from task adaptation.

2. **Carrier-aware recoverability**
   distinguishing explicit encoding, lexical/contextual substitution, basis exhaustion, and research burden.

3. **Source-grounded mediation**
   treating native identity, attachment, citation, sequence, and pointer relations as admissible bridges into scholarly discovery.

4. **Access -> relation -> warrant decomposition**
   separating whether evidence enters the active evidence set from how it is related and what claims it later licenses.

5. **Native / workflow / controlled / reference representation separation**
   preventing an author-built reference reconstruction from acting as an ecological "ideal."

6. **Source-verified transition-episode corpus**
   a small mechanistic corpus with seed states, hidden targets, native provenance, workflow traces, boundary/null cases, and claim-state separation.

7. **Independent DH infrastructure pressure test**
   Frankenstein, Whitman, and Faust test different representational boundaries while preserving their native scholarly semantics.

## Manuscript rule

The paper must not say that support feasibility, contract-relative adequacy, source binding, or generic state quotienting are invented here.

The novelty claim should instead concern their substantive re-specification for scholarly representation and the empirically grounded mechanism chain:

\[
representation
\rightarrow
mediation/access
\rightarrow
relation recovery
\rightarrow
humanistic warrant.
\]

## Self-overlap control

When text or formal notation from prior papers is reused:
- rewrite for the present scholarly object;
- cite the prior paper where conceptually material;
- do not reproduce prior proofs or benchmark claims as if they were new evidence;
- distinguish methodological ancestry from current empirical validation.
